В блоке «SQL и базы данных» выполнялся проект «Онлайн-каталог сотрудников», в рамках которого создавалась база данных сотрудников крупной компании (более 50000 человек), содержащая следующие данные: ФИО, должность, дату приема на работу и размер заработной платы. У каждого сотрудника был один начальник. 

В данном  же проекте  разработана система управления персоналом с удобным поиском сотрудников и возможностью изменения некоторых данных.

Что сделано: 

Разработано веб-приложение на основе Flask и SQLAlchemy, отображающее информацию о сотрудниках из базы данных и предоставляющее функционал поиска и обновления данных.

Что содержится в проекте:

Python 3.13

Flask

Flask-SQLAlchemy
PostgreSQL 

Git (для управления версиями кода)

В данной базе данных на 50000 сотрудников (PostgreSQL) имеется возможность удобного просмотра,поиска, добавления, редактирования и удаления любого сотрудника.
